暮らしのお手伝いを相談する

引っ越しの手伝い、大型家具の移動、蜂の巣駆除など、暮らしのお手伝いのご相談を、LINEで受け付けています。

案内所は、作業を行う事業者ではありません。ご相談内容を受け付け、相談内容に応じた地域の専門業者をご紹介する窓口です。

暮らしのお手伝いで相談できること

  • 引っ越しの手伝い
  • 大型家具の移動
  • 蜂の巣駆除
  • オリジナルデザインTシャツの作成

これらは一例です。内容によっては、ご案内できない場合があります。対応できるかどうかは、ご相談内容や業者の状況によって異なります。対応をお約束するものではありません。

相談するときに伝えておくとよい情報

  • ご希望の内容（どんなお手伝いが必要か）
  • 作業する場所（家の中・庭・軒先 など）
  • 量や数の目安（家具の大きさや数、Tシャツの枚数 など、分かる範囲で）
  • 希望する日時や時期
  • 状況が分かる写真（任意）

分からない項目は、空欄のままで大丈夫です。蜂の巣駆除は、安全のため、ご自身で駆除しようとせず、蜂に近づかないようにしてください。

専門業者へ相談するまでの流れ

  1. LINEで相談内容を送る
    このページの「このことで相談する」から、同意の確認のうえ、LINEで相談内容を送ります。
  2. 案内所が専門業者へ転送する
    内容を、対応できる地域の専門業者へLINEで転送します。電話番号などの共有には、事前に同意をいただきます。
  3. 専門業者が電話で直接ご連絡する
    ご同意いただいた電話番号へ、専門業者が直接お電話し、専門的なご相談や、現地確認・日程調整を行います。
  4. 依頼するかどうかを決める
    専門業者の説明を聞いたうえで、依頼するかどうかは、ご自身で決めていただけます。

専門業者からの連絡や、問題の解決をお約束するものではありません。

料金と依頼について

料金は、専門業者へ直接ご確認ください。案内所では、料金のご案内や見積もりは行いません。

相談したからといって、依頼する義務はありません。
